# Forgejo source control

Helm starter values; initialize Forgejo through its web UI, create an admin user, and configure outbound webhook access to Jenkins. Use PostgreSQL, object storage, SMTP, TLS and tested backups before production. SQLite is a one-instance local default and is not HA. Store webhook secrets in product secret stores. Official [Docker installation](https://forgejo.org/docs/latest/admin/installation/docker/) supports standalone evaluation.
